# Proposals

This folder contains formal proposals for changes to the framework.

## How to Submit a Proposal

1. Create a new Issue with the template "Proposal: [Title]"
2. Clearly state:
   - What you want to change
   - Why it should be changed
   - Technical or legal justification
3. After discussion, a Pull Request may be created
