# Submission Guide to International Organizations

This document outlines how to present this framework to global institutions.

## Target Organizations (Priority Order)

1. **AMAS (ITU/ISO/IEC)** - Highest priority (authenticity standards)
2. **C2PA** - Technical provenance
3. **OECD.AI**
4. **UNESCO** (Ethics of AI)
5. **Council of Europe (CAI)**
6. **European Commission (AI Act)**
7. **G7/G20 Digital Groups**

## Recommended Package

- This README
- Problem Statement
- Framework + Justification
- Technical Metrics
- Roadmap + Governance

We aim to submit Version 1.0 as a **community-driven open standard**.
