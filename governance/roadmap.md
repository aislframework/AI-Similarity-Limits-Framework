# Roadmap

- Core documents
- Initial framework definition
- Multi-language support (EN, PT-BR, ZH)

## Phase 0.2 - Community Building (Next 30-60 days)
- Attract contributors
- Open discussions on thresholds and metrics
- Collect research references

## Phase 1.0 - Stabilization (3-4 months)
- Refined technical justification
- First version ready for external review
- Submission package preparation for ITU/ISO, OECD.AI, UNESCO, etc.

## Phase 2.0 - Validation & Tools (6-12 months)
- Empirical benchmarks
- Prototype tools (similarity calculators)
- National adaptation guides

## Long-term Vision
Become a recognized open standard for objective AI content regulation.
