# Governance and Decision Making

## How Decisions Are Made

This project uses **rough consensus** combined with transparent discussion.

### Process for Important Changes

1. Proposal is opened as an Issue (with clear justification)
2. Minimum 14 days of community discussion
3. Maintainers evaluate feedback
4. If strong consensus is reached → changes are merged
5. If significant disagreement → proposal may be split or archived

## Threshold Changes

Changing the core thresholds (70/85/95) requires:
- Strong technical justification
- Supporting data or research
- At least 3 independent contributors in favor

The goal is to keep the framework stable but improvable.
