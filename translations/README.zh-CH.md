# AI-Similarity-Limits-Framework

## 人工智能相似度限制框架

**为生成式人工智能与深度伪造监管设定的客观相似度阈值**

司法主观性 + 人工智能 = 混乱  
本框架用**可测量的客观相似度阈值**取代了“可识别性”或“看似真实”等模糊标准。

---

### 原始框架 (v0.1)

- **相似度 < 70%**：自由使用 —— 视为“通用人物形象”
- **相似度 70% - 85%**：允许使用，但必须附带强制性免责声明
- **相似度 85% - 95%**：需获得被相似者的明确同意
- **相似度 > 95%**：视为严重违规（在有害情境下可能构成犯罪），除非获得明确授权

---

### 为什么需要这个项目？

目前，法官主要依据情感证词和主观感知来判决深度伪造案件。  
本仓库旨在建立一个**开放的、经过同行评审的、可在全球范围内采纳的技术标准**，以减少这种主观性。

---

### 主要技术指标

- 面部嵌入（ArcFace / CosFace）
- 语音嵌入
- 感知指标（LPIPS、SSIM）
- FID 及其他指标

本框架是**迭代式**的，并承认其自身存在的局限性（包括对抗性攻击）。
